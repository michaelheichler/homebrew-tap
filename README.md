# Homebrew tap of Michael Heichler

## Samsung Scan

[Samsung Scan](https://github.com/michaelheichler/samsung-scan) is a scanning app for the Mac.

Install it with this command.

```sh
brew install --cask michaelheichler/tap/samsung-scan
```

Homebrew also installs the free SANE scanner drivers. To update the app, run `brew upgrade --cask samsung-scan`.

The release workflow of Samsung Scan updates the cask in this repository for each new version.
